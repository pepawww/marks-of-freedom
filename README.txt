MARKS OF FREEDOM — SITE V3

This version contains all three exported OBJ models:
- models/tattoo-01.obj = Tattoo 1_2
- models/tattoo-02.obj = Tattoo 2_2
- models/tattoo-03.obj = Tattoo 3_2 (Peony)

HOW TO RUN
1. Open the folder in VS Code.
2. Open index.html.
3. Run with Live Server (Go Live).
4. In the 3D Archive, switch between 01 / 02 / 03.
5. Drag to rotate and scroll to zoom.
6. Tattoo 03 has the current Symbol / Freedom / Words annotations.

Note: the OBJ files are large, especially Tattoo 03. We can optimise/convert them to GLB later before final publication.
